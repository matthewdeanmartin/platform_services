## 2026-11-01 — GitHub Projects sprint support

Query: `site.docs.github.com projects iteration field sprints`

Source: [GitHub Docs — About iteration fields](https://docs.github.com/en/issues/planning-and-tracking-with-projects/understanding-fields/about-iteration-fields)

Finding: Projects supports repeating iterations with adjustable date ranges, durations, and breaks, plus current/previous/next iteration filters.

## 2026-11-01 — Sprint fields versus project views

Query: `site:docs.github.com projects iteration fields views same items`

Sources: [About iteration fields](https://docs.github.com/en/issues/planning-and-tracking-with-projects/understanding-fields/about-iteration-fields), [Customizing views](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project), [Customizing the board layout](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/customizing-the-board-layout).

Finding: Iterations are item metadata; views can filter/group the same project items. Changing a card's status in a board updates that item's status. An undated single-select Sprint field can represent phases without prescribing calendar iterations.
